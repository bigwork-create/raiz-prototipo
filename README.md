# Raiz — prototipo

Prototipo clicable (PWA) de Raiz, para revisar el diseño y el flujo en el celular o en la computadora.

**No hay backend real.** Los datos son de prueba y se guardan solo en este navegador (`localStorage`). El código SMS aparece en pantalla como **código de prueba**. Las fotos de DNI y la selfie se eligen desde el teléfono (cámara o archivos); no se envían a un servidor.

## Cómo probarlo

1. Abre el sitio publicado (GitHub Pages) o esta carpeta con un servidor estático.
2. Crea una cuenta con un número +51, escribe el código de prueba, define una contraseña y envía la verificación.
3. En **el mismo navegador y el mismo dispositivo**, entra como administrador y aprueba esa solicitud. Luego cierra sesión y vuelve a entrar con la cuenta nueva.
